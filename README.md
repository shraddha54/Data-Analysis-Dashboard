# Data-Analysis-Dashboard
 HR Analysis Project
This project focuses on analyzing HR data to uncover insights related to employee attrition using a provided Excel dataset.

📁 Data Used
HR Data Excel File – contains employee details including age, gender, department, job satisfaction, education field, and attrition status.

✅ Key Highlights
✔️ Calculated KPIs:

Total Employee Count

Total Attrition Count

Attrition Rate

Active Employees

Average Employees

✔️ Visualizations Created:

📌 Pie Chart – Department-wise Attrition Distribution

📌 Bar Graph – Number of Employees by Age Group

📌 Rating Chart – Job Satisfaction Ratings

📌 Grouped Bar Chart – Education Field vs. Attrition

📌 Gender-based – Attrition Rate by Gender

📌 Age-based – Attrition Rate by Age Groups

🎯 Objective
Understand attrition patterns

Identify high-risk groups

Support HR with data-driven decisions
